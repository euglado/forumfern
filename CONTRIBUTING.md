# Contributing / Katkı

Use Node 24.x and `npm ci --ignore-scripts`. Run `npm run check`, `npm audit --audit-level=low`, both Node helper syntax checks and `bash -n setup.sh register.sh start.sh` in a checkout without secret files. Format with `npx biome check --write .`. Keep permissions minimal, API reads bounded, Turkish/English explanations consistent and tests meaningful. Explain the behavior changed and validation performed in each PR. Avoid adding message content/member-list intents, telemetry or public sharing to this private browser without discussing the privacy impact. Never include real tokens/server data in fixtures. Actual mobile/screen-reader feedback is welcome; describe client/version and behavior without private screenshots.
